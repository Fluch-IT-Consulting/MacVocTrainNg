# Triage-Labels

Die Skills sprechen von fünf Triage-Rollen. Hier stehen die Labels, die dieses Repo
dafür benutzt.

| Rolle in mattpocock/skills | Label hier | Bedeutung |
| -------------------------- | ---------- | --------- |
| `needs-triage` | `needs-triage` | Der Maintainer muss das Issue bewerten |
| `needs-info` | `needs-info` | Wartet auf weitere Informationen |
| `ready-for-agent` | `ready-for-agent` | Vollständig beschrieben, ein Agent kann es allein umsetzen |
| `ready-for-human` | `ready-for-human` | Braucht einen Menschen, z. B. Bedienung der App oder Entscheidungen zum Aussehen |
| `wontfix` | `wontfix` | Wird nicht umgesetzt |

Zusätzlich:

- `architektur-review`: Herkunft aus einem Architektur-Review, siehe `issue-tracker.md`
- `blocked`: wartet auf etwas außerhalb des Repos

Neue Issues bekommen `needs-triage`, bis der Maintainer sie eingeordnet hat.
